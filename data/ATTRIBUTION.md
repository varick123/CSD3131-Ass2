# Evaluation inputs

`demo/scene_1.png` through `scene_8.png` are deterministic procedural test patterns generated by the project's `seamcarve demo` command: isolated subject, buildings/straight lines, diagonals, checker texture, multiple subjects, border frame, thin strokes and gradient. They are synthetic tests, not photographs.

The four files in `photos/` were obtained from the official scikit-image repository at tag **v0.25.2**, directory [skimage/data](https://github.com/scikit-image/scikit-image/tree/v0.25.2/skimage/data). They are evaluation inputs only; no scikit-image seam algorithm is used. Attribution and status are recorded by the project's [official data documentation](https://scikit-image.org/docs/0.25.x/api/skimage.data.html).

`tools/evaluate.py` creates explicitly resized evaluation copies using Pillow LANCZOS. All three seam methods then receive the same copy, target and energy policy. The script records actual dimensions, raw measurements, composites and input hashes. Downsampling prepares a common bounded benchmark and is not presented as seam carving. The scaling baseline uses Pillow BILINEAR separately and is labeled as such.
