# Sample input

`tiny_gradient.ppm` is a deterministic 6x4 binary PPM (P6) RGB fixture. Its pixels are `(40*column, 70*row, 20*(row+column))`. It has no external image dependency or attribution requirement.

Use it to start image-loading and energy tests once those modules are implemented. Add a varied, attributed image set for the actual visual-quality evaluation; this tiny gradient is not sufficient for that comparison.
